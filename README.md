# Hafssa ❤️ — Petite invitation

Petit site responsive pour téléphone et PC.

## Hébergement gratuit

### Option 1 — GitHub Pages
1. Crée un repository public sur GitHub, par exemple `hafssa-date`.
2. Mets `index.html`, `style.css` et `script.js` à la racine.
3. Dans **Settings → Pages**, choisis **Deploy from a branch**, puis `main` / `/root`.
4. GitHub te donnera une adresse du type `https://TON-USERNAME.github.io/hafssa-date/`.

### Option 2 — Netlify
Tu peux aussi déposer le dossier du site dans Netlify pour obtenir une URL gratuite.

## Important
Le bouton WhatsApp ouvre une conversation vers le numéro configuré dans `script.js`.
Le message est généré automatiquement avec le jour, l'heure, le repas et la dernière réponse.
